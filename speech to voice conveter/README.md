# Speech to Voice Converter

A text to speech converter built with HTML, CSS and JavaScript using the Web Speech API. Type anything and listen to it spoken aloud in your choice of voice.

## Features
- Type any text and convert it to speech
- Select from multiple available voices via dropdown
- Uses browser's built-in Web Speech API — no external library needed

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Web Speech API (SpeechSynthesisUtterance)

## How to Run

Open `index.html` directly in your browser — no setup needed!

> Voice options depend on the voices available in your browser and OS.
