# Age Calculator

A simple age calculator built with HTML, CSS and JavaScript that calculates your exact age in years, months and days from your date of birth.

## Features
- Date input with max set to today's date so future dates can't be selected
- Calculates exact age in years, months and days
- Handles month and day borrowing logic accurately

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

Open `index.html` directly in your browser — no setup needed!
