# To-Do App

A simple to-do list app built with HTML, CSS and JavaScript with localStorage persistence so tasks stay saved even after page refresh.

## Features
- Add new tasks
- Mark tasks as completed by clicking on them
- Delete tasks with the × button
- Tasks persist in localStorage — data stays after refresh

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage

## How to Run

Open `index.html` directly in your browser — no setup needed!
