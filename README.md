# Frontend Mini Projects

This repository contains small frontend projects created while practicing HTML, CSS, and JavaScript fundamentals.

## Projects

1. **Age Calculator** - A simple project that calculates your exact age in years, months, and days based on your date of birth. Built using HTML, CSS, and JavaScript with DOM manipulation and date handling.

2. **Animated Menu Bar** - A stylish navigation bar with smooth open and close animations. Built using HTML, CSS animations, and JavaScript for toggle functionality.

3. **BG Random Color** - A fun project where clicking a button changes the background to a randomly generated color. Built using JavaScript's Math.random() for color generation and DOM manipulation.

4. **Calculator** - A fully functional calculator that performs basic arithmetic operations like addition, subtraction, multiplication, and division. Built using HTML, CSS, and JavaScript.

5. **Calendar** - An interactive monthly calendar that lets you navigate between months and view dates. Built using JavaScript Date object and DOM manipulation.

6. **Digital Clock** - A real-time digital clock that displays the current hours, minutes, and seconds live. Built using JavaScript's setInterval() and Date object.

7. **Drag and Drop** - A project with draggable UI elements using the JavaScript Drag and Drop API. Allows users to pick up and reorder elements on the page.

8. **Generate Random Password** - A customizable password generator that creates strong passwords and lets you copy them to clipboard instantly. Built using JavaScript with character set logic.

9. **Hide and Show Password** - A simple toggle that switches password visibility in input fields. Built using JavaScript and DOM manipulation.

10. **Image Gallery** - A responsive image gallery with a lightbox-style preview on click. Built using CSS Grid and JavaScript for overlay functionality.

11. **Image Search Engine** - A project to search and display images using the Unsplash API. Built using Fetch API, async/await, and dynamic DOM rendering.

12. **Insta Login Page** - An Instagram-inspired login page UI clone. Built purely with HTML and CSS to practice layout and styling.

13. **Newsletter Tailwind** - A clean newsletter subscription form styled with Tailwind CSS utility classes. Focuses on responsive design and Tailwind-based layouts.

14. **Notes App** - A note-taking app where you can create, save, and delete notes. Data persists using localStorage so notes stay even after refresh.

15. **OTP Generator** - Generates a random 6-digit OTP and displays it on screen. Built using JavaScript's Math.random() and DOM manipulation.

16. **Password Strength Checker** - A real-time password strength indicator that shows weak, medium, or strong feedback as you type. Built using JavaScript regex and conditional logic.

17. **Popup** - A simple modal/popup component with open and close functionality. Built using HTML, CSS, and JavaScript event listeners.

18. **Progress Bar** - An animated progress bar that fills up with a percentage display. Built using CSS transitions and JavaScript for dynamic value updates.

19. **QR Code Generator** - Generates a QR code from any text or URL you enter. Built using a QR code library and JavaScript DOM manipulation.

20. **Quiz App** - A multiple-choice quiz that tracks your score and shows the result at the end. Built using JavaScript arrays, objects, and conditional rendering logic.

21. **Quote Generator** - Fetches and displays random motivational quotes from an external API. Built using Fetch API and async/await.

22. **Select Menu** - A custom-styled dropdown select menu built from scratch using HTML, CSS, and JavaScript instead of the default browser style.

23. **Speech to Voice Converter** - Converts typed text into spoken audio using the Web Speech API. Built with JavaScript's SpeechSynthesis interface.

24. **Stopwatch** ⏱️ - A stopwatch with start, stop, and reset functionality along with lap tracking. Built using JavaScript's setInterval() and array-based lap storage.

25. **To-Do App** - A task manager where you can add, complete, and delete tasks. Data persists using localStorage so your list stays after page refresh.

26. **Travel Blog** - A visually rich travel blog layout with cards, sections, and a clean UI. Built using HTML and CSS to practice layout and design skills.

27. **Weather App** 🌤️ - Fetches and displays live weather data for any city using a weather API. Built using Fetch API, async/await, and dynamic DOM updates.
