# Weather App 🌤️

A weather app built with HTML, CSS and JavaScript that fetches and displays live weather data for any city using the OpenWeatherMap API.

## Features
- Search any city to get live weather data
- Displays temperature, humidity and wind speed
- Dynamic weather icon changes based on condition — Clouds, Clear, Rain, Drizzle, Mist
- Shows error message for invalid city name

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Axios (via CDN)
- OpenWeatherMap API

## Setup

1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Replace the `apiKey` value in `app.js` with your own key
3. Open `index.html` directly in your browser — no setup needed!
