# Drag and Drop

A simple drag and drop project built with HTML, CSS and JavaScript using the native Browser Drag and Drop API.

## Features
- Drag list items from the left box to the right box and back
- Built using native dragstart, dragover and drop events — no libraries needed

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

Open `index.html` directly in your browser — no setup needed!
