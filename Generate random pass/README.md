# Random Password Generator

A simple password generator built with HTML, CSS and JavaScript that generates a random 12-character password and lets you copy it to clipboard.

## Features
- Generates a random 12-character password with uppercase, lowercase, numbers and special characters
- Copy to clipboard with a single click
- Does not copy if the password field is empty

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

Open `index.html` directly in your browser — no setup needed!
